# 차근차근 큐브

실물 3×3 큐브를 한 층씩 맞추는 한국어·영어 매뉴얼입니다.

- [한국어](https://namu-cube.pages.dev/)
- [English](https://namu-cube.pages.dev/en/)

흰 십자부터 1층·2층·3층 순서로 배우며, 움직이는 큐브와 단계별 설명을 제공합니다. 학습 기록은 이용 중인 브라우저에 저장됩니다.

홈의 ‘시작 지점 찾기’에서 내 큐브의 시작 조건에 맞는 본 수업을 고를 수 있습니다. 진행 표시는 직접 확인한 본 수업 7개만 세며 준비·흰 꽃 설명은 포함하지 않습니다. 수업에서는 사례 고르기, 잡는 방향, 시연 따라 하기, 실물 확인을 차례로 안내합니다.

막힘 복구 도움말을 펼치면 진행 중인 한 동작을 마친 뒤 시연이 멈춥니다. 화면과 실물이 다를 때의 확인 방법과 마지막 꼭짓점 단계의 일시적인 아래층 변화를 설명합니다. 화면 되돌리기는 실물을 되돌리지 않습니다.

사례를 고르면 실제 시작 상태를 위·앞·오른쪽에서 본 그림과 조건이 함께 표시됩니다. 그림은 실제 모델을 렌더링한 PNG이며, 재생 중에도 시작 상태를 유지하므로 시연 전 모습과 비교할 수 있습니다. 사례 데이터·좌표·색상을 바꾸면 `npm run render:cases`로 25개 이미지를 다시 만듭니다. 이 명령은 로컬 Chrome(또는 `CHROME_PATH`)을 사용하며 서버가 필요 없습니다. `npm run test:site`는 이미지 원본과 현재 데이터의 일치 여부도 검사합니다. 전체 색 배치가 같을 필요는 없으며 찾는 조각과 주변 가운데 색을 비교합니다.

큐브는 마우스·터치 드래그 또는 초점을 둔 상태의 방향키로 상하·좌우를 관찰합니다. 모바일 페이지는 큐브 바깥에서 스크롤합니다. 큐브 영역에서도 두 손가락 확대는 브라우저에 맡깁니다. 아랫면 보기 버튼을 다시 누르면 직전 시점으로 돌아오고, ‘기본 방향’ 또는 Home 키는 기본 시점을 복원합니다. 관찰 조작은 조각 상태를 바꾸지 않습니다.

예시 재생은 동작 묶음의 확인 지점에서 멈춥니다. 실물의 새 모양을 확인한 뒤 다음 동작이나 묶음 재생으로 이어갑니다. 마지막 수업은 두 시작 방향 모두 다음 꼭짓점 이동과 최종 정렬을 거쳐 여섯 면이 완성될 때까지 이어집니다.

큐브 바로 위에는 기본 공식을 큰 기호로 표시합니다. 반복 횟수와 공식 사이의 정렬은 따로 안내하며 ‘예시 전체 순서와 정렬 보기’에서 확인할 수 있습니다. 설명을 읽느라 공식이 화면 위로 사라지면 하단 참고 띠가 나타납니다. ‘이 묶음 다시 보기’는 화면의 현재 확인 묶음을 재생하고, ‘공식 가리고 연습’은 기호와 다음 동작 설명을 가립니다. ‘공식 복사’는 기본 공식만 복사합니다.

밝은·어두운 화면은 시스템 설정을 따릅니다. 상단의 테마 버튼으로 바꾸면 같은 브라우저에서 선택을 저장합니다. 저장소가 차단되어도 현재 화면의 테마 전환과 수업은 이용할 수 있습니다.

로컬 실행은 `npm ci` 후 `npm run dev`입니다. `npm test`, `npm run check`, `npm run build`, `npm run test:site`로 검증합니다. 브라우저 검사는 개발 서버를 켜고 `npm run test:browser`를 실행합니다. Chrome 경로는 `CHROME_PATH`, 서버 주소는 `BASE_URL`로 지정할 수 있습니다.
