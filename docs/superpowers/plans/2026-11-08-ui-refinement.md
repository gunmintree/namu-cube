# 사례 이미지와 조작 배치 정리

## 요청과 판단

사용자는 사례 선택 영역의 큰 크기와 어색한 그림, 버튼처럼 보이지 않는 조작, 반복되는 내용과 위치를 묶어서 수정하도록 요청했다. Figma 및 이미지 생성 활용 여부는 맡겼다. 기존 제품 방향과 학습 모델을 유지하면서 실제 화면을 수정했다.

- 사례 그림은 색 배치가 학습 조건이므로 기존 좌표 모델을 투명 PNG로 렌더링한다. 임의로 그린 색 배치를 사용하지 않는다.
- 사례·잡는 방향은 하나의 준비 구역으로 묶고, 준비 → 시연 → 실물 확인의 세 번호로 표시한다.
- 모바일에서는 선택 상자를 전체 폭으로 두고 100px 그림 옆에 조건·비교 안내를 둔다. 잡는 방향은 바로 이어서 읽는다.
- 공식 복사·가리기는 공식 아래, 아랫면·기본 방향은 큐브 위, 반복·초기화·속도는 재생 조작 아래에 둔다.
- 목적지로 이동하는 요소는 링크 의미를 유지하며 필요한 주요 이동에 버튼 외형을 적용한다. 펼침은 native details/summary를 유지한다.
- 흰 십자 순서의 중복 설명과 하단의 반복된 일곱 단계 탐색을 제거한다. 방법 안내와 흰 조각 모으기 도움말은 유지한다.

## 검증

회전 알고리즘·기록 형식·실물 완료 조건은 바꾸지 않았다. 단위 검사 49개, 타입 검사(오류·경고·힌트 0개), 25개 페이지 빌드·사이트 검사, 브라우저 검사 70개가 통과했다. 브라우저 검사에는 모든 사례 이미지 로드, 시작 이미지 고정, 모바일 버튼 위치, 양언어·320~1280px·키보드·움직임 감소·터치 관찰·no-JS를 포함한다. 브라우저 검사는 최종 빌드를 로컬 4324 포트에서 실행했다.

수정 화면은 모바일·태블릿·데스크톱 및 어두운 테마에서 확인했다. 독립 검토에서 발견한 첫 동작 후 버튼 이동과 PNG 파일 검증의 공백을 수정했다. 재검토에서 활성 상태의 다음 동작 버튼 이동은 0px였다.

Figma 연결은 확인했으며 별도 디자인 파일 생성·가져오기는 수행하지 않았다. 실제 초보자 평가, 실기기 사용성 평가, 공개 배포는 이 수정의 검증 결과에 포함하지 않는다.
