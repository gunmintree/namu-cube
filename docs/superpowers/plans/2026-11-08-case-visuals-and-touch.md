# 사례 그림·보조 버튼·모바일 관찰 개선

사용자가 기존 기획의 구현 범위 확인과 버튼 일관성, 사례 선택의 그림, 모바일 상하 관찰을 요청했다. 추가 선택 질문 없이 한 묶음으로 진행한다.

## 범위와 결정

- 기존 고도화의 이번 구현 범위는 이미 반영됐다. 실제 초보자 평가와 그 결과에 따른 개선은 남아 있다.
- 이어보기는 기존 보조 버튼 모양, 플레이어의 보조 조작은 44px 이상의 작은 보조 버튼 체계로 정리한다. 탐색 링크의 의미와 기존 동작은 보존한다.
- 사례 선택 아래에 위·앞·오른쪽에서 본 실제 시작 상태의 SVG 그림을 제공한다. 기존 정수 좌표 모델과 `getFaceGrid`를 사용하며 이미지 생성이나 새 라이브러리는 필요하지 않다.
- 그림은 선택한 사례의 시작 상태다. 시연의 동작을 진행해도 시작 그림은 고정하며 사례를 바꾸면 함께 갱신한다. JavaScript 미사용에서도 첫 사례 그림과 조건을 읽는다.
- 한 손가락의 큐브 영역 드래그는 상하·좌우 관찰, 영역 밖은 페이지 스크롤이다. `touch-action: pinch-zoom`으로 브라우저 확대 동작을 남긴다. 관찰은 스티커 상태·수순을 바꾸지 않는다.

## 실행 순서

1. 실제 사례와 그림의 27개 색 배치 동기화, 시작 그림 고정, 모바일 양축 관찰·영역 밖 스크롤을 브라우저 검사에 추가하고 구현 전 실패를 확인한다.
2. `CasePreview.astro`와 `lesson.ts`를 연결하고 사례 선택·모바일 관찰 안내를 구현한다.
3. `CubeIndex.astro`, `Formula.astro`, `Lesson.astro`, `site.css`의 보조 조작을 같은 체계로 정리한다.
4. 한국어·영어, 320~1280px, 200% 글자, 두 테마와 기존 복사·관찰·재생 검사를 수행한다.
5. 제품·디자인·실행 문서를 변경 범위에 맞게 갱신하고 검증한 변경을 로컬 커밋으로 정리한다.

## 검증과 한계

`npm test`, `npm run check`, `npm run build`, `npm run test:site`, `npm run test:browser` 및 대표 화면 검사를 수행한다. 모바일 제스처 자동화는 터치 에뮬레이션이며 실기기·실제 초보자의 학습 성과 검증과 구분한다.

## 실행 결과

- 시작 그림 부재와 세로 터치 관찰 차단을 브라우저 검사에서 먼저 재현했다. 구현 뒤 같은 두 검사가 통과했다.
- SVG 세 면의 27개 색은 흰 십자·2층·마지막 꼭짓점의 각 선택 사례 시작 상태와 대조했다. 재생 중 시작 그림 고정과 JavaScript 미사용의 첫 사례 그림을 확인했다.
- 이어보기와 플레이어 보조 조작의 버튼 체계를 맞췄다. 아랫면 보기·공식 복사는 공식 제목 가까운 한 묶음으로 배치하고, 다시 보기와 재생 버튼 사이의 간격을 확보했다.
- 모바일의 가로·세로 드래그가 관찰 방향만 바꾸고 스티커는 보존되는지 확인했다. 큐브 안의 페이지 이동 차단과 큐브 밖의 페이지 스크롤을 터치 에뮬레이션으로 확인했다.
- 최종 검증: Node 테스트 49/49, Astro 검사 23파일 0 errors/warnings/hints, 정적 빌드·사이트 검사 25페이지, 최종 정적 빌드 브라우저 검사 69/69 통과.
- 390·1280px의 실제 화면과 두 테마를 확인했다. 브라우저 회귀 검사는 320·360·390·768·1280px, 200% 글자, 한국어·영어, 복사 거부 시 대안·저장소 차단·키보드·움직임 감소를 포함한다.
- 독립 코드 검토에서 Critical/Important/Minor 결함은 보고되지 않았다. 기계적 디자인 검사는 기존 문맥별 글자 크기의 advisory 22개와 non-advisory 0개를 보고했다. 경고만 없애기 위해 기존 글자 크기를 통일하지 않았다.
- 실기기에서의 손가락 조작·핀치 확대와 실제 초보자의 이해도·완료율은 아직 평가하지 않았다. 새 그림을 실물 인식이나 성공률 개선의 근거로 표현하지 않는다.
- 실행 로그와 화면은 로컬 `artifacts/verification/followup-*`, `artifacts/followup/`에 보존하며 Git에 포함하지 않는다.
