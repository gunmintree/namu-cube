# 3×3 초보 과정의 기준과 검증

확인일: 2026-11-07. 대상: 일반 색상 3×3 큐브를 혼자 보고 따라 배우는 초보자와 어린 독자. 실제 아동의 이해도나 혼자 완성할 수 있는지는 아직 확인하지 않았다.

## 참고한 1차 설명

- [Rubik’s 공식 3×3 Solve Guide](https://rubiks.com/solve-guide): 조각 종류, 노란 가운데를 위에 두는 자세, 흰 꽃에서 색을 맞춘 흰 십자로 이동하는 절차를 확인했다. 공식 안내의 후반 순서 전체를 가져온 것은 아니다.
- [J Perm의 3×3 초보 안내](https://jperm.net/3x3): 흰 십자를 아래에 놓는 첫 층 처리, 네 동작 반복, 가운데 층에서 잘못 낀 모서리를 꺼내는 분기와 재확인 방식을 참고했다. 이 자료의 마지막 단계는 큐브를 뒤집는 방식이므로 여기의 마지막 단계와 혼용하지 않는다.
- [Ruwix 저자의 초보 해법](https://ruwix.com/the-rubiks-cube/how-to-solve-the-rubiks-cube-beginners-method/): 좌우 가운데 층 삽입과 노란 층의 십자 → 모서리 자리 → 꼭짓점 자리 → 꼭짓점 방향 순서를 확인했다. 마지막 네 동작을 완전히 마치고, 꼭짓점 사이에는 윗층만 움직이라는 조건을 반영했다.

문장과 그림을 복제하지 않고 학습 문구와 시연 상태를 새로 작성했다. 서로 다른 출처의 자세를 그대로 이어 붙이지 않고 아래 규칙으로 통일했다.

## 이번 개편

본 과정은 흰 십자부터 시작하는 7단계다. 준비와 흰 꽃은 별도 보조 설명이다. 마지막의 두 시작 사례는 첫 꼭짓점, 다음 꼭짓점 이동, 남은 회전과 마지막 윗층 정렬을 같은 시연에서 보여준다. 확인 지점에서 멈추며, 마지막에는 여섯 면이 맞아야 한다. 일반적인 마지막 방향 조합은 별도 27개 방향 검사로 확인한다.

## 이 과정의 고정 규칙

화면의 완성 상태는 U 노랑, D 흰색, F 초록, R 빨강, B 파랑, L 주황이다. 모든 수업에서 노랑 위·흰색 아래를 유지한다. 실물에서 새 조각의 집을 정할 때는 큐브 전체를 수평으로 돌려 앞면을 고를 수 있지만, 하나의 동작 묶음 도중에는 앞면을 바꾸지 않는다. 마지막 방향 단계는 시작 후 큐브 전체를 돌리지 않는다.

면 기호는 해당 면을 바깥에서 정면으로 바라본 시계 방향 90°다. 작은따옴표는 반시계 방향, 2는 180°다. D는 아랫면의 회전이며 큐브 전체를 뒤집는 동작이 아니다. 넓은 층 회전·가운데 층 기호·큐브 전체 회전 기호는 사용하지 않는다.

| 단계 | 동작 또는 확인 규칙 | 끝나는 조건 |
| --- | --- | --- |
| 준비 | 면 하나를 돌리고 역동작으로 돌아오기 | 조각 종류와 잡는 방향 확인 |
| 흰 꽃 | 빈 윗자리 확보 후 흰 모서리를 위로 이동 | 노란 가운데 주위 흰 모서리 네 개 |
| 흰 십자 | 꽃잎의 옆 색 정렬 후 해당 면 반 바퀴 | 아래 흰 십자와 네 옆 색 일치 |
| 흰 꼭짓점 | 집 바로 위에서 `R U R' U'` 반복 | 첫 층의 세 색 일치 |
| 가운데 층 | 오른쪽 `U R U' R' U' F' U F`, 왼쪽 `U' L' U L U F U' F'` | 아래 두 층 일치 |
| 노란 십자 | `F R U R' U' F'`, 매 묶음 뒤 모양 재정렬 | 네 노란 모서리가 위를 봄 |
| 노란 모서리 | `R U R' U R U2 R' U` | 네 옆 색이 가운데와 일치 |
| 노란 꼭짓점 자리 | `U R U' L' U R' U' L` | 세 색이 맞는 집에 네 꼭짓점 배치 |
| 방향과 완성 | `R' D' R D` 2회 또는 4회, 다음 조각은 U로 이동 | 노란 꼭짓점 방향과 마지막 윗층 정렬 후 여섯 면 일치 |

노란 모서리 동작은 마지막 U까지 포함할 때 앞·왼쪽 두 모서리를 교환한다. 이웃한 두 옆 색이 맞으면 맞는 둘을 뒤·오른쪽에 둔다. 마주 보는 둘이 맞는 예시는 앞·뒤에 두고 위 동작, U2, 위 동작, U를 차례로 수행한다. 이 변형도 실제 상태로 검사했다.

꼭짓점 자리 동작은 위·앞·오른쪽의 자리를 고정하고 다른 셋의 자리를 순환시킨다. 방향까지 고정한다는 뜻은 아니다. 맞는 꼭짓점이 없으면 한 묶음 후 찾고, 하나면 그 자리를 잡아 반복하고, 네 개면 건너뛴다.

## 시연 상태와 실제 큐브의 차이

각 사례는 `완성 상태 → targetSetup → moves의 역동작`으로 준비한다. 재생하면 그 사례의 목표 상태에 도달한다. 흰 꽃의 목표는 `F2 R2 B2 L2`로 만든 꽃이며, 꺼내기 사례는 다음 삽입을 준비하는 중간 상태다. 나머지 여러 시연의 다른 조각은 미리 맞아 있다. 따라서 한 사례의 재생이 끝났다는 이유로 실물의 단계 전체가 끝난 것은 아니다.

실물에서는 사례의 조건을 먼저 확인하고, 한 묶음 뒤 다시 관찰하며, 완료 조건에 맞을 때 다음 단계로 간다. 상태 촬영·색 입력·자동 인식·임의 섞임 자동 해법은 제공하지 않는다. 마지막 두 시연은 인접한 두 꼭짓점의 방향 예시다. 실제로 세 개 또는 네 개가 틀어졌다면 각각의 노란 면을 관찰해 같은 자리에서 처리해야 한다.

## 실행 검증과 한계

`tests/lessons.test.ts`는 언어별 필수 문구·경로 중복·유효 회전 기호·동작별 설명 수와 함께 실제 큐브 모델로 다음을 검사한다.

- 사례 시작 상태의 꽃잎 위치·흰 꼭짓점 방향·중간 모서리의 색·노란 모양·자리 조건.
- 흰 십자의 옆 색과 첫 층·아래 두 층의 보존.
- 점 → 재정렬된 ㄱ → 선 → 십자 이동 중간 상태.
- 노란 모서리의 이웃/마주 보는 분기와 꼭짓점 자리의 0/1/4개 조건.
- 마지막 단계 중 아래층이 일시적으로 달라졌다가 모든 동작 후 여섯 면이 복원되는 결과.

수학적 상태 검사와 학습 사용성 검증은 다르다. 이 검사는 가능한 모든 섞임에서 독자가 올바른 사례를 고르는지, 작은 손으로 동작할 수 있는지, 한 번에 설명을 이해하는지 입증하지 않는다. 실물 큐브와 독자를 통한 사용성 검증이 필요하다. 그림 큐브나 센터 방향을 맞춰야 하는 변형 큐브는 대상이 아니다.

구현 중 상태 검사로 발견한 오류는 수정했다. 가운데 층 꺼내기 예시의 시작 상태를 윗모서리에 노랑이 모두 포함되는 실제 뒤집힌 중간 모서리로 바꾸었고, 점 예시의 첫 묶음 뒤 정렬은 U2로 바로잡았다. 흰 꽃의 아래·옆 사례는 불필요하고 성립하지 않는 빈자리 조건을 제거했다.
